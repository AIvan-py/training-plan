# План тренировок

Страница с планом тренировок и питания, которую можно поставить ярлыком на главный экран телефона.

**Адрес:** https://aivan-py.github.io/training-plan/

## Ярлык на телефон

- **iPhone:** открыть адрес в Safari → «Поделиться» → «На экран „Домой“» → «Добавить».
- **Android:** открыть адрес в Chrome → кнопка «Добавить на главный экран» на странице или меню ⋮ → «Добавить на главный экран».

После первого открытия план работает без интернета.

## Что где

- `index.html` — сам план.
- `dl/` — PDF всей программы и картинки по дням.
- `manifest.webmanifest`, `icons/` — название и иконка ярлыка.
- `sw.js` — офлайн-режим. Если меняете файлы в `dl/`, поднимите версию `CACHE` в начале файла.
